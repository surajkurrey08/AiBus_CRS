Keep the existing orange action tokens, cream page background, white panels and restrained borders from the admin stylesheet. Show gross booking value separately from posted platform earnings. Financial totals and actions require explicit finance grants, even for a bootstrap Super Admin. Manual document reference review is labelled as such: the interface does not imply uploaded files, automated KYC or an available file vault. Settings template edits are drafts, not sent notifications.
